# 眼镜试戴原型

## 项目背景
家里经营老花镜，希望用户在微信里试戴自家眼镜，并在未来由本人或家人选择商品。优先考虑老年用户看近处不清的情况：大字、易操作、家人协助；长期目标是戴着旧眼镜也可试戴新款。当前先使用自家眼镜的正面和侧面照片，不做3D建模。

## 2026-11-05 更新
- 增加人脸取景框和逐步加载状态；框只作提示，不要求脸贴合。
- 根据脸部关键点自动缩放镜框，默认系数比上一版减小约 21%，仍需真机测试。
- 增加识别模型加载超时与重试提示。

## 已完成
- 手机网页原型，真实商品正面和侧面照片、AI处理的镜框透明素材。
- 使用 MediaPipe Face Landmarker 进行摄像头人脸追踪，镜框图片叠加、大小调整和保存照片。
- 原型发布地址（仅站点所有者可访问）：https://jingkuang-shidai-demo.wavyaria2.chatgpt.site/

## 尚未完成和限制
- 旧眼镜去除、语音指引、微信小程序、3D多角度、商品和支付均未实现。
- 实时跟脸和手机摄像头功能尚未进行真实设备实测；生成式处理的透明图可能改变商品细节。图片叠加不能准确判断尺寸或舒适度。
- 站点使用本地提供的 MediaPipe 脚本及模型；GitHub 源码首次运行前需要通过 setup_assets.py 下载依赖。视频在浏览器本地处理；不要宣称系统功能已经全面测试。
- 不以屏幕测试估算老花镜度数；专业验光数据与实际验配为准。

## 本地运行
Python 3：先在项目根目录运行 `python setup_assets.py` 下载识别组件和模型（需要访问 npm 和 Google），再运行 `python -m http.server 8000 --directory dist`，在本机浏览器打开 http://localhost:8000/ 并授权摄像头。手机访问通常需要 HTTPS 安全地址；localhost 只指当前设备。首次运行前需要下载安装模型。

## 重要文件
- `dist/index.html`：完整网页、样式和识别逻辑。
- `dist/front.png`、`dist/side.png`：用户提供的实物图片。
- `dist/frame.png`：AI根据正面照片生成的透明镜框，非严格保真。
